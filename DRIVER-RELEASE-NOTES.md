# Backwoods Driver 0.5.0

Completed invoice history by local delivery date, confirmed customer signatures,
full-page/80 mm printing, a shared Driver clock, authorized shift GPS recovery,
and secure administrator-approved invoice revisions.

Install the Windows setup once to add App updates. The previous Driver 0.4.0
Windows application did not contain this updater. Future verified Windows
updates use the separate Driver update feed.

The Android download is **Backwoods Driver (New)**, package
`com.backwoodsbrew.driver.next`. It is a separate first installation because the
original Driver signing key is unavailable. It keeps the original Driver app and
its data in place. Finish synchronizing pending work in the original app before
switching. Use the same Backwoods username and password. Future updates to this
new package use its retained signing key and native App updates screen.

The Employee 0.4.2 companion must run its Owner service on the Windows PC
containing the actual Employee records. Keep that PC online to synchronize HR
views and validate invoice approvals. Driver payroll jobs and existing company
Accounting ownership must be reviewed; no new employees, wages, retail stores or
company books are invented. Closed-period/refund corrections remain for Finance.

Windows install/upgrade, actual Android OS workflows, isolated Firebase security,
browser signatures/printing, shared timekeeping and the existing Accounting
posting engine are checked before publication. Physical tablet/printer hardware
and the owner's live Windows service still need device verification. No business
transactions or payments were created by these tests.
