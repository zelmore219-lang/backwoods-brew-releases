# Backwoods Employees 0.4.4 — paper onboarding and Driver assignment

On the existing employee profile, select **Prepare paper onboarding packet**, enter the actual handbook reference and paper-file storage location, approve the checklist, then select **Approve and assign paper packet**. The required packet contains Federal W-4, Alabama A-4, Form I-9, Employee handbook acknowledgment and Emergency contact form. Missing assignments are added, unfinished older versions are replaced with approved acknowledgment instructions, and existing approved records and signatures remain retained. New hires receive the configured required packet automatically; **Assign required packet** safely catches up existing employees without duplicates.

Employees complete and sign the paper originals and return them to owner / HR. In **My workspace → View → Acknowledge paper completion**, they type their full name, confirm paper completion and signature consent, and select **Sign acknowledgment**. A different owner / HR reviewer uses **Documents → Review** to confirm the completed signed paper original and its secure file reference, then **Approve document**. Paper Form I-9 additionally requires the authorized verifier's examination procedure, dates, evidence, eligibility/examination confirmations and retention date. No upload is required for these paper assignments; the actual official forms and human verification remain required. Other existing electronic/upload workflows retain their checks.

Activation now also identifies required packet documents that have not yet been assigned. Existing account, password, job, training and separate-review requirements still apply. Payroll setup remains outside activation; HR.my can remain the payroll workflow.

The **Create shared login** form now includes **Driver app** and **Driver role**. Select **Delivery driver** for an ordinary driver; Main and Wholesale are optional for that role. Keep **Employee Management portal** selected so the employee can complete onboarding. Driver managers also need explicitly approved **Wholesale Vendor Ordering → Manager** access for the existing route and financial review tools.

For someone who already has a shared login, keep their existing employee record and use **People → View → Application access → Assign access → Driver app → Delivery driver → Save**. The account service applies the Driver profile to the same Firebase UID and preserves the existing password and other approved application access. Confirm the Driver row is **active**. Do not create a second account for an existing employee.

Driver uses that person's shared Backwoods username and password. Finish any temporary-password change in Employee before using the other applications. Payroll job mapping remains a separate reviewed step under **Time & attendance → Shared time cards**; no retail store or payroll job is guessed from the Driver grant. Required forms still need approved acknowledgments and separate review; account, job and training checks remain enforced. Keep Owner service running on the owner Windows PC.

Owner connection also gains the normal **Edit** menu and a **Paste authorization code** button. The window explains that the five-character session ID identifies the browser session; the one-time authorization code comes from the browser's final **Step 3 of 3 — Copy code** page. Clipboard access occurs only after the owner explicitly selects Paste in the trusted owner window.

This release updates Windows only. Existing records, encrypted documents, owner connection and Main sign-in stay in place. The existing signed Android update is retained. Use **App updates → Check for updates**, install 0.4.4, then reopen Employee and confirm Owner service is online. The installer and checksum are attached to this release.
